# Security Policy

WSLC Rookery is an informal, community tool. It is **not** an official Microsoft
product and is **not** covered by Microsoft support or the Microsoft Security
Response Center (MSRC). Please do **not** report issues to MSRC or
secure@microsoft.com — they are out of scope for this project.

## Reporting a vulnerability

Please report suspected vulnerabilities **privately** rather than via public
issues, using GitHub's private vulnerability reporting:

- Go to the **Security** tab → **Report a vulnerability**
  (https://github.com/alexsmithMSFT/wslc-rookery/security/advisories/new)

Include what you found, affected version/commit, reproduction steps, and impact.

As a hobby project maintained on a best-effort basis, there is no guaranteed
response time and no bug bounty. See [SUPPORT.md](SUPPORT.md) for support scope.
